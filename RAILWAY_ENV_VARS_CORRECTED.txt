# ============================================================================
# TROUBLESHOOTING
# ============================================================================

## Error: "does not match pattern smtps?:\\/\\/.*"
- Check MAILTRAP_SMTP_URI starts with smtp:// (not smtps://)
- Ensure no extra spaces or quotes
- Format: smtp://username:password@smtp.mailtrap.io:2525

## Error: "expected integer, got string" (for port)
- Don't set port in kratos.yml
- Railway handles port binding automatically
- Kratos will listen on 0.0.0.0:4433 by default

## Error: "not valid uri" (for CORS origins)
- Ensure KRATOS_BROWSER_URL is full HTTPS URL
- Must include https://
- No trailing slash
- Must be set before Kratos starts

## Error: "Bad Gateway" or 502
- Check backend logs for startup errors
- Verify DATABASE_URL is set correctly
- Ensure migrations completed successfully
- Check that PORT binding worked (Railway assigns PORT env var)

## Sessions not persisting
- Verify COOKIE_DOMAIN=.up.railway.app
- Check browser cookies are being set
- Ensure both services use same domain suffix
